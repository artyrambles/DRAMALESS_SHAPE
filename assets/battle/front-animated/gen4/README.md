# Generation 4 animated front sprites

Source reference: [Diamond and Pearl sprites — Bulbagarden Archives](https://archives.bulbagarden.net/wiki/Category:Diamond_and_Pearl_sprites)

```powershell
python tools/import_animated_sprites.py --set gen4 --root .
```

The importer converts the first 151 animated PNGs into local atlases. Artwork
is ignored by Git and is not covered by the mod's MIT license. Verify that you
have the right to use and distribute it.
