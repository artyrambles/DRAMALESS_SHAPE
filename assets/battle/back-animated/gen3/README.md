# Generation 3 animated back sprites

Source reference: [Emerald back sprites — Bulbagarden Archives](https://archives.bulbagarden.net/wiki/Category:Emerald_back_sprites)

From the repository root, run:

```powershell
python tools/import_emerald_back_sprites.py --root .
```

This generates the local `Spr b 3e` atlases here and their shared Lua
metadata. Generated artwork is ignored by Git and is not covered by the
mod's MIT license. Verify that you have the right to use and distribute it.
