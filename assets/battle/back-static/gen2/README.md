# Generation 2 static back sprites

Source reference: [Pokémon Crystal back sprites — Bulbagarden Archives](https://archives.bulbagarden.net/wiki/Category:Crystal_back_sprites)

```powershell
python tools/import_crystal_back_sprites.py --root .
```

The importer discovers the ordinary `2c`, `2g`, or `2s` file for each of the
first 151 species. Artwork is ignored by Git and is not covered by the mod's
MIT license. Verify that you have the right to use and distribute it.
